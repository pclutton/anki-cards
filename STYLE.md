# Anki Card Style Guide

*Edit this file to control how your flashcards are generated.*

---

## Card Types
- **Definitions & facts** → Cloze deletion (fill in the blank)
- **Processes & explanations** → Basic Q&A (question front, answer back)
- **Key vocabulary** → Basic + Reversed (tests both term→definition AND definition→term)

## Answer Style
- Keep answers SHORT — max 3 bullet points where possible
- Use plain English first, then technical terms
- Always include a concrete example or analogy if helpful
- No long paragraphs — if it needs a paragraph, split into two cards

## Extras
- Include a mnemonic where one exists or can be invented
- Include the Latin/Greek root for new biological terms
- For multi-step processes (e.g. mitosis, Krebs cycle) — one card per step, plus one overview card
- Tag cards by difficulty: easy / medium / hard

## Topics to Emphasise
- Exam-style questions (past paper style where possible)
- Anything the lecturer said "this will be in the exam"
- Common misconceptions worth flagging

## Topics to Avoid
- Trivial definitions already covered in earlier decks
- Anything marked [SKIP] in source material

## Current Deck Structure
*Update this when new decks are added*
- Anatomy S2::Heart
- Anatomy S2::Immune
- Anatomy S2::Circulatory

## Topic Request Files
Write these in Topics Requested/ as plain .md files.
- Treat `## Special Emphasis` as high priority — generate more cards on these,
  use past-paper phrasing, and tag them `exam-priority`
- If a `## Source File` is named, use it as the primary source and cross-reference it
- If `## Source File` is `(none)`, generate cards from general knowledge
